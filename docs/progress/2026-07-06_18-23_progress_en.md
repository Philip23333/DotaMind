# DotaMind Progress Snapshot: 2026-07-06 18:23

- **Agentic layer** ([stratz_tools.py](apps/api/app/agentic/tools/stratz_tools.py)):
  - `HeroPositionStatsInput` adds `selection_mode: strong/popular` (default strong) + `min_sample_size` (default 300).
  - `_hero_position_stats_handler`: both branches use selection_mode (no "silently ineffective arg") — `position_id` branch filters -> sorts -> truncates by take; `hero_id` branch filters -> sorts but **does NOT truncate** (returns the hero's full position distribution ranked by win rate, answering "strongest position").
  - `hero_position_stats_evidence` value adds `match_win_rate` + `win_count` + `win_rate_basis="match: winCount/matchCount"` (top-level + filters mirror); filters carries selection_mode; new `selection_policy` string.
  - description rewritten: selection_mode/min_sample_size apply to both branches, take only truncates the position_id branch.
- **planner** ([planner.py](apps/api/app/agentic/planning/planner.py)): `Supported` section adds position capabilities (highest win rate / most picked / strongest position); selection_mode guidance adds position (same semantics as lane_meta, both branches).

## Key Design

- Position win-rate caliber = winCount/matchCount (match-level), basis `"match: winCount/matchCount"`, distinct from lane's `"match: matchWinCount/matchCount"` (same caliber, different field).
- selection_mode reuses lane_meta's strong/popular semantics but applies to both branches (hero_id no truncation / position_id truncates take), avoiding silently-ineffective args.
