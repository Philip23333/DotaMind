## 行为边界

- `/api/v1/query` 不变。
- `/debug/chat` 不变。
- `/api/v1/plan` 是独立实验链路。
- 当前只允许使用已注册的真实 v2.5 tools：
  - `resolve_hero`
  - `stratz.hero_vs_hero_matchup`
- 当前工具不足时直接返回 `status="insufficient_tools"`。
- 不包装旧 team/meta/patch/claim pipeline。
- 不生成最终自然语言回答。

## Planner Validation

- 所有 tool name 必须已注册。
- `constraints.allow_mock` 必须为 `false`。
- `tool_calls` 不得超过 `constraints.max_tool_calls`。
- `stratz.hero_vs_hero_matchup.hero_id` 必须使用引用：
  - `"$resolve_target.data.hero.hero_id"`
- `counter_pick` plan 必须包含 required evidence：
  - `hero_identity`
  - `matchup_win_rate`
  - `sample_size`
- 不接受 LLM 自造 hero_id、未知工具或自然语言工具名。
