# MetaMind 进度快照：2026-06-29 15:50

> 本文记录 `/api/v1/plan` 当前链路的 Planner、EvidenceGraph、AnswerSynthesizer 契约修复。

## 本次更新

- 修复 `natural_language_answer`：
  - `NaturalLanguageAnswerSynthesizer` 不再要求 LLM 输出 JSON。
  - 改为使用普通文本 completion，再由代码包装为统一 `AnswerSynthesisResult`。
  - LLM 失败仍返回 `answer.status="error"`，不 fallback，不 mock。
- 修复 `opendota.hero_stats_by_role` 的 evidence 映射：
  - 稳定产出 `hero_stats`。
  - 稳定产出 `role_fit`。
  - 新增 `sample_size` evidence，使用 role-filtered hero rows 数量。
- 收紧 Planner validation：
  - 拒绝未知 `output_contract`。
  - 拒绝未知 `required_evidence`，避免 LLM 自造 `hero_name`、`win_rate` 等 evidence kind。
  - `role_meta_report` 只允许 `hero_stats`、`role_fit`、`sample_size`。
  - `role_meta_report` 必须要求 `hero_stats`。
- 修复 `response_node` 的 `response_type`：
  - `answer.status="insufficient_evidence"` -> `insufficient_evidence`
  - `answer.status="error"` -> `answer_error`
  - 结构化报告成功时返回对应 contract，例如 `role_meta_report`
  - 自然语言回答成功时返回 `natural_language_answer`

## 边界

- 未修改 `/api/v1/query`。
- 未修改 `/debug/chat`。

- 未新增 mock 或 fallback。
