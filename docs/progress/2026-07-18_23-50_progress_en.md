# DotaMind Progress Snapshot: 2026-07-18 23:50

## Controller contract review fixes

- Fixed minimum evidence obligations losing `tool_call_id` identity. Contract
  and plan evidence remain global kind obligations; registry mandatory evidence
  is now checked separately for every successful tool call.
- Added authoritative global/per-call obligations to
  `RequiredEvidenceResolution` and AgentRunState. `decision_validate_node`
  recomputes and writes them back on every successful validation.
- EvidenceGraph now exposes `mandatory_evidence_by_call`. Missing per-call proof
  is recorded as `<call_id>:<kind>`, and completeness counts global and per-call
  obligation instances.
- Reference-resolution failures now create failed ToolResults and map to
  `error/tool_error` instead of `raw_tool_results`.
- Added an `execution_error` response fallback and stable terminal reasons, so
  downstream failures no longer return or persist `decision accepted`.
- All LLM-facing Controller decisions and ConversationBasis use
  `ConfigDict(extra="forbid")`; unknown fields enter validation retry.

## Regression coverage

- Two calls of the same tool with only one extractor producing mandatory
  evidence: the other reports `call_b:main` and completeness 0.5.
- Missing reference path: emits a reference-resolution ToolResult and returns
  tool_error.
- Unclassified runtime error: returns execution_error and a stable reason.
- Tool/answer failures use `tool execution failed` and
  `answer generation failed` respectively.
- A capability decision carrying an unknown `plan` field is rejected as a
  decision validation error.
- A Controller result with stale empty evidence resolution is recomputed and
  written back before EvidenceGraph processing.
