## 层界划分（评审发现的两类遗留问题，均不在 planner prompt 层）

1. **"strongest" 措辞偏差（answer 层）**：`lane_meta_global` 按 `match_count` 选 top-N（工具描述明确警告 "common not strongest"），答案却把这些「最热门组合里胜率靠前」的标成 "the strongest ally lane pairs"。属 answer 节点未 honoring 工具描述里的 caveat，**非 prompt 问题**（caveat 已在 prompt 的工具描述中）。
2. **时间窗缺口（上游工具层）**：`context.week` 是单 epoch、"最近两周"是区间，语义不匹配；且 planner **无获取当前 week epoch 的能力**，故 prompt 里「for last N weeks use the most recent week epoch」实际是空指引，模型只能置 None。根因是工具/数据层缺失，**非 prompt 措辞问题**。
