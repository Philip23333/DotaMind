# DotaMind 进度快照：2026-06-29 16:54

> 本文记录 `/api/v1/plan` 的 Tool Evidence Extractor 注册化重构。

## 本次更新

- `ToolDefinition` 新增可选字段：
  - `evidence_extractor`
  - `evidence_kinds`
- `EvidenceGraph` 不再按 tool name 写死 extractor 分支。
- `build_evidence_graph(plan, tool_results, registry)` 现在从 `ToolRegistry` 读取 tool definition：
  - 有 `evidence_extractor` 时生成 `EvidenceItem`
  - 没有 extractor 时保留 `ToolResult`，不生成 evidence
  - 未知 tool 或 extractor 异常会进入 `missing`
- 已迁移现有 extractor 到对应 tool 模块：
  - `stratz_tools.py`：`resolve_hero`、`stratz.hero_vs_hero_matchup`、`stratz.lane_outcome`
  - `opendota_tools.py`：team / player / hero stats 相关 tools
  - `patch_tools.py`：patch records / hero changes / item changes
- `Planner` 的 known evidence kinds 改为从 registry 的 `definition.evidence_kinds` 汇总。
- `evidence_node` 现在显式接收 registry 并传给 EvidenceGraph。

## 边界

- 未新增业务 tool。
- 未修改 `/api/v1/query`。
- 未修改 response schema。
- 未新增 fallback。
- 未新增 mock。
- `ToolExecutor` 仍只负责执行 tool，不直接生成 evidence。
