# DotaMind 进度快照：2026-06-25 16:19

> 本文记录 `/api/v1/plan` 从线性 service / PlanRunner 混合模式，激进拆分为 LangGraph-compatible Tool / Node 模式。

## 本次更新

- 新增 `apps/api/app/agentic/nodes.py`：
  - `planner_node`
  - `validate_plan_node`
  - `tool_executor_node`
  - `evidence_node`
  - `answer_node`
  - `critic_node`
  - `formatter_node`
- 新增 `apps/api/app/agentic/graph.py`：
  - `AgentGraphRunner`
  - 负责最小条件流转，不引入 LangGraph runtime。
- 删除 `PlanRunner / PlanRunResult`：
  - 删除 `apps/api/app/agentic/runner.py`
  - 引用解析迁入 `tool_executor_node`
  - plan validation 迁入 `validate_plan_node`
  - evidence graph 构建迁入 `evidence_node`
- 删除 `PlanFormatter`：
  - 删除 `apps/api/app/agentic/formatter.py`
  - `formatter_node` 直接写入 `AgentRunState.response`
- 简化 `ToolExecutor`：
  - 删除 `execute_plan()`
  - 保留单工具执行 `execute(call)`
- 更新 `PlanService`：
  - 只创建 `AgentRunState`
  - 调用 `AgentGraphRunner`
  - 不再直接编排 planner/runner/answer/critic。
- 修正 Planner contract：
  - counter-pick plan 必须使用 `output_contract="draft_advice"`
  - validation 拒绝 `counter_pick + tool_results`。

## 当前链路

```text
AgentGraphRunner
  -> planner_node

  -> tool_executor_node
  -> evidence_node
  -> answer_node
  -> critic_node
  -> formatter_node
```
