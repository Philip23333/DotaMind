## 本次同步

- `dev-api.cmd` 固定监听 `127.0.0.1:8001`，启动前检查 `8001` 是否已有 `Listen` 连接。

- 根目录 `package.json` 的 `npm run dev:api` 改为调用 `dev-api.cmd`。
- `README.md`、`apps/api/README.md` 和 `docs/technical/api.md` 的本地后端地址从 `8000` 同步为 `8001`。
