# DotaMind 进度快照：2026-06-29 17:35

> 本文记录 Planner JSON 解析失败时的 raw content 可观测性增强。

## 本次更新

- 新增 `LLMJSONDecodeError`，用于在 `complete_json()` 解析失败时携带未解析的 LLM `content`。
- `complete_json()` 在 `json.loads(content)` 失败时抛出 `LLMJSONDecodeError`，并保留：
  - `raw_content`
  - `finish_reason`
  - 原始 JSON parse error
- 日志只记录 `raw_content` 长度和错误信息，不打印完整半截内容。
- `AgenticPlannerResult` 新增：
  - `raw_content`
  - `finish_reason`
- Planner 捕获 `LLMJSONDecodeError` 后仍返回 `status="error"`，不 fallback，但会把半截 planner content 写入结果。
- `/api/v1/plan` response 新增：
  - `planner_raw_content`
  - `planner_finish_reason`
- `/debug/plan` 页面新增 `Planner Raw Content` 区块，用于显示 Planner JSON 被截断时的原始半截内容。

## 边界
