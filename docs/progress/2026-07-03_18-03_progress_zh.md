# MetaMind 进度快照：2026-07-03 18:03

> 本文记录本轮“STRATZ 官方 GraphQL schema 文档化”改动。范围是新增可重复下载官方 introspection schema 的脚本，并生成聚焦 hero stats / time filtering 的技术摘录。

## 修改总结

- **目标**：把 STRATZ GraphiQL 左侧 Docs 的官方 schema 来源固化到仓库，避免继续依赖手工截图、浏览器搜索或抓包猜测字段签名。
- **新增脚本**：
  - `apps/api/scripts/stratz_schema_docs.py`
  - 读取 `METAMIND_STRATZ_TOKEN` / `METAMIND_STRATZ_GRAPHQL_URL`（环境变量优先，随后 `apps/api/.env`）。
  - 向 `https://api.stratz.com/graphql` 发 GraphQL introspection 查询，请求头包含官方要求的 `User-Agent: STRATZ_API`。
  - 输出 raw introspection JSON 与聚焦 Markdown 摘录。
- **新增文档产物**：
  - `docs/technical/stratz_schema_introspection.json`：官方 introspection 原始 JSON，约 2.1 MB。
  - `docs/technical/stratz_schema_reference.md`：从 schema 自动生成的重点字段摘录。

## 关键发现

- 官方 schema 明确 `HeroStatsQuery.winDay` 是日粒度趋势来源：
  - 返回 `[HeroWinDayType]`
  - 参数包含 `heroIds`、`take`、`skip`、`bracketIds`、`positionIds`、`regionIds`、`gameModeIds`、`groupBy`
  - `HeroWinDayType` 字段为 `day`、`heroId`、`winCount`、`matchCount`
- 这确认 `/heroes/meta/trends` 截图中的日期级 tooltip 应来自 `winDay`，胜率由 `winCount / matchCount` 计算。
- `laneOutcome` / `heroVsHeroMatchup` / `stats` 仍属于 `week: Long` 周桶模型；后续工具设计应把 day-grain `winDay` 和 week-grain lane/matchup/stat 工具分开。
- 官方 schema 对 `week=null` 的描述是 “current week”，但本项目 2026-07-03 实测记录显示 null 等于 latest completed week；新摘录文档已注明：schema 作为字段契约，`docs/design/time_patch_filtering.md` 作为 null-week 行为实证记录。
