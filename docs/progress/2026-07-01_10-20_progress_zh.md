# MetaMind 进度快照：2026-07-01 10:20

> 本文记录 planner prompt renderer 强化和 `/debug/plan` 模型输入展示。

## 本次更新

- 强化 `render_planner_tools(registry)`：
  - 每个 tool 现在明确渲染 `allowed_arg_keys`。
  - 每个 tool 明确渲染 `produced_evidence_names_must_be_exact`。
  - 参数引用同时渲染结构化 `accepted_ref` 和可读的 `accepts reference from ...`。
  - 工具输出 path 通过 `declared_output_paths` 展示。
  - 明确提示 planner 只能使用列出的 arg keys，不能发明别名或同义词。
- 强化 `render_planner_contracts(registry)`：
  - 每个 output contract 现在渲染 `required_evidence_names_must_be_exact`。
  - 明确提示 `required_evidence` 必须逐字从 contract / tool evidence 名称中复制，不能发明同义词。
- 强化 planner system prompt：
  - 增加 schema obedience rules。
  - 明确 tool name、args keys、output_contract、required_evidence 必须逐字使用 catalog 中的名字。
  - 明确禁止 `current_roster`、`matches` 等自然语言同义词替代真实 schema 名称。
- 增加 debug 可观测性：
  - `AgenticPlannerResult` 新增 `prompt_messages`。
  - `/api/v1/plan` response 新增 `planner_prompt_messages`。
  - `/debug/plan` 页面新增 `Planner Prompt Messages` 折叠块，展示实际发送给 LLM 的完整 system/user messages。
