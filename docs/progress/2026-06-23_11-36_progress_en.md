# MetaMind Progress Snapshot: 2026-06-23 11:36

> This document records the team-report data credibility and freshness update.

## Updates

- Added structured `data_freshness` output to team reports so callers can judge whether the evidence is recent enough.
- `data_freshness` includes:
  - `latest_match_time` / `latest_match_at`: latest match timestamp inside the requested window.
  - `sample_window_days`: parsed sample-window size in days.
  - `matches_in_window`: all match summaries inside the requested window.
  - `match_details_analyzed`: match detail sample actually fetched and analyzed.
  - `opendota_cache_hits` / `opendota_cache_misses`: OpenDota transport cache hits and misses during this team-report retrieval path.
- `/debug/chat` now displays latest match time, sample window, detail sample size, and OpenDota cache hit/miss status in team reports.
- Updated `docs/technical/api.md` with the new `data_freshness` fields.

## Design Notes

- Existing root-level `matches_in_window` and `match_details_analyzed` fields are preserved for compatibility.
- Freshness is emitted as a nested object to avoid adding more low-level diagnostic fields to the team report root.
- OpenDota cache status is derived from actual transport cache stat deltas, not inferred by the UI or Formatter.
