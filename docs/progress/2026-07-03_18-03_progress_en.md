# MetaMind Progress Snapshot: 2026-07-03 18:03

> This snapshot records the "STRATZ official GraphQL schema documentation" update. Scope is adding a repeatable downloader for official introspection schema and generating a focused technical excerpt for hero stats / time filtering.

## Modification Summary

- **Goal**: make the official schema behind the STRATZ GraphiQL Docs panel durable in the repository, instead of relying on screenshots, browser search, or inferred request captures.
- **Added script**:
  - `apps/api/scripts/stratz_schema_docs.py`
  - Reads `METAMIND_STRATZ_TOKEN` / `METAMIND_STRATZ_GRAPHQL_URL` from environment first, then `apps/api/.env`.
  - Sends a GraphQL introspection query to `https://api.stratz.com/graphql` with the official `User-Agent: STRATZ_API` header.
  - Writes raw introspection JSON and a focused Markdown excerpt.
- **Added documentation artifacts**:
  - `docs/technical/stratz_schema_introspection.json`: raw official introspection JSON, about 2.1 MB.
  - `docs/technical/stratz_schema_reference.md`: generated excerpt of the key schema fields.

## Key Findings

- The official schema confirms `HeroStatsQuery.winDay` is the day-grain trend source:
  - returns `[HeroWinDayType]`
  - args include `heroIds`, `take`, `skip`, `bracketIds`, `positionIds`, `regionIds`, `gameModeIds`, and `groupBy`
  - `HeroWinDayType` fields are `day`, `heroId`, `winCount`, and `matchCount`
- This confirms the date-level tooltip in the `/heroes/meta/trends` screenshot should come from `winDay`; win rate is computed as `winCount / matchCount`.
- `laneOutcome` / `heroVsHeroMatchup` / `stats` remain `week: Long` weekly-bucket fields. Future tool design should keep day-grain `winDay` separate from week-grain lane/matchup/stat tools.
- The official schema description says `week=null` gives "current week", but this project recorded live evidence on 2026-07-03 that null matched the latest completed week. The generated excerpt now notes: use the schema as the field contract, and `docs/design/time_patch_filtering.md` as the empirical behavior record for null-week semantics.
