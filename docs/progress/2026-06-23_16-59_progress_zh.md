# DotaMind 进度快照：2026-06-23 16:59

> 本文记录 v2.5 Tool Registry 最小闭环的新增。

## 本次更新

- 新增 `apps/api/app/agentic/` 包，作为 v2.5 受约束 Tool Calling 的内部骨架。
- 新增核心模型：
  - `ExecutionPlan`
  - `ExecutionConstraints`
  - `ToolCall`
  - `ToolResult`
  - `ToolSource`
- 新增工具注册与执行层：
  - `ToolDefinition`
  - `ToolRegistry`
  - `ToolExecutor`
- 新增第一个真实工具：
  - `stratz.hero_vs_hero_matchup`
  - 输入：`hero_id`、`take`、`week`、`bracket_basic_ids`、`match_limit`
  - 输出：STRATZ hero matchup 的 advantage / disadvantage 数据。
- 新增 debug runner：
  - `apps/api/scripts/agent_tool_debug.py`
  - 用于从命令行执行已注册工具并返回标准 `ToolResult`。

## 设计边界

- 本次没有接入旧 `/api/v1/query` 链路。
- 本次没有修改旧的 `pipeline/orchestrator.py`、`pipeline/retriever.py` 或报告生成链路。
- 当前目标是建立工具调用最小闭环，为后续 Orchestrator 输出 `ExecutionPlan` 做准备。

- `python -m ruff check app tests scripts` 通过。
- `python scripts/agent_tool_debug.py --tool stratz.hero_vs_hero_matchup --hero-id 25 --take 3` 成功返回真实 STRATZ 数据。

## 当前能力

当前已经可以通过标准化路径执行真实工具：

```text
ToolCall
  -> ToolRegistry
  -> ToolExecutor
  -> stratz.hero_vs_hero_matchup
  -> STRATZ GraphQL
  -> ToolResult
```

返回结果包含：

- `status`
- `data`
- `source`
- `latency_ms`
- `error`
- `metadata`
