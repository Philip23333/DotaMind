## Follow-up fix: `_placeholder` returns a single-element list

End-to-end verification found: the planner passes a `$ref` for filter `candidate_rows`; at validation time `_replace_references` substitutes the `$ref` with `_placeholder(list[dict])=[]` (empty), tripping `FilterHeroesByPositionInput.candidate_rows`'s `min_length=1` -> `too_short` error.

Fix ([contracts.py](apps/api/app/agentic/planning/contracts.py) `_placeholder`): list types return `[element placeholder]` (e.g. `list[dict] -> [{}]`) instead of `[]`. This way `min_length` checks don't misfire on `$ref` placeholders; the real value is supplied by `_resolve_reference` at execution time.
