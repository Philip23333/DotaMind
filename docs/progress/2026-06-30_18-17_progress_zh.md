# DotaMind 进度快照：2026-06-30 18:17

> 本文记录 Tool Contract Runtime 的契约一致性修正。

## 本次更新

- 修复 AcceptedRef 类型一致性风险：
  - 新增 `validate_registry_contracts(registry)`。
  - 校验 `arg_contracts` 是否引用真实 input field。
  - 校验 `AcceptedRef.type` 是否与目标字段 `input_model` annotation 兼容。
  - 校验 `AcceptedRef.from_tool/path/type` 是否匹配源工具声明的 `output_paths`。
- 移除 `ArgContract.required` 漂移点：
  - required/optional 展示只来自 Pydantic `input_model.model_fields[name].is_required()`。
  - `arg_contracts` 继续只表达字段语义和可接受引用。
- 补充测试：
  - dummy contract 覆盖目标字段类型不兼容。
  - dummy contract 覆盖未知 arg contract。
  - dummy contract 覆盖 accepted ref type 与 source output path type 不一致。
