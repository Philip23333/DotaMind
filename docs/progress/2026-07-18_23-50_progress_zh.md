# DotaMind 进度快照：2026-07-18 23:50

## Controller 契约审查修复

- 修复最低证据义务丢失 `tool_call_id` 维度的问题。contract 与 plan evidence
  继续按全局 kind 校验；registry mandatory evidence 现在按每个成功工具调用
  分别校验。
- `RequiredEvidenceResolution` 与 AgentRunState 新增 authoritative global/per-call
  obligation；`decision_validate_node` 每次重新计算并覆盖写回 state。
- EvidenceGraph 新增 `mandatory_evidence_by_call`。缺失 per-call evidence 使用
  `<call_id>:<kind>`，完整度按全局义务与每调用义务的实例总数计算。
- 引用解析失败现在生成 `status=error` 的 ToolResult，并稳定映射为
  `error/tool_error`，不再落入 `raw_tool_results`。
- response 增加 `execution_error` 兜底，并按终态覆盖稳定 reason，避免下游失败
  仍返回或持久化 `decision accepted`。
- 所有 LLM-facing Controller decision 与 ConversationBasis 使用
  `ConfigDict(extra="forbid")`，未知字段进入 validation retry。

## 回归覆盖

- 同一工具调用两次、仅一次 extractor 产生 mandatory evidence：另一调用返回
  `call_b:main`，完整度为 0.5。
- 引用路径不存在：生成 reference-resolution ToolResult，并返回 tool_error。
- 未分类运行时 error：返回 execution_error 与稳定 reason。
- tool/answer failure：reason 分别为 `tool execution failed` 和
  `answer generation failed`。
- capability decision 携带未知 `plan` 字段：返回 decision_validation_error。
- Controller result 携带空旧 evidence resolution：Graph validation 会重新计算并
  写回 mandatory evidence，再用于 EvidenceGraph。
