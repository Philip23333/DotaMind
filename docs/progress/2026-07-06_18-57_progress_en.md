## Modification Summary

- **New bracket translation** ([brackets.py](apps/api/app/integrations/stratz/brackets.py)): `basic_to_full(list[str] | None) -> list[str] | None`. None/[] -> None (no bracketIds); non-empty maps (DIVINE_IMMORTAL->[DIVINE,IMMORTAL] etc., UNCALIBRATED->[UNCALIBRATED]); unknown raises ValueError. Used only by winDay (other tools keep basic).
- **Integration layer** ([heroes.py](apps/api/app/integrations/stratz/heroes.py)): adds `_HERO_WIN_DAY_QUERY` (`winDay(heroIds, take, bracketIds:[RankBracket], positionIds, regionIds, gameModeIds)`) + `hero_win_day` method (per row `{day, win_count, match_count, win_rate}`; preserves STRATZ order day desc; **does not use _resolve_week_window**).
- **Agentic layer** ([stratz_tools.py](apps/api/app/agentic/tools/stratz_tools.py)): registers `stratz.hero_daily_trends` (input hero_id/take<=12; handler calls basic_to_full then hero_win_day; returns daily_buckets + filters with bracket_basic/bracket_full/grain=day; evidence kind=`hero_daily_trend` single, no per-day sample_size; value carries `win_rate` + `win_rate_basis="day: winCount/matchCount"` mirror).
- **planner** ([planner.py](apps/api/app/agentic/planning/planner.py)): `Supported` section adds daily trend (day-grain, not weeks_back); bracket guidance adds UNCALIBRATED.
- **answer** ([synthesizer.py](apps/api/app/agentic/answer/synthesizer.py)): `_NATURAL_LANGUAGE_SYSTEM_PROMPT` adds day-grain phrasing guidance (hero_daily_trend describes the trend across calendar days, distinct from per-week).

## Key Design

- day-grain does not use weeks_back: winDay is calendar days (recent N days), not the weekly bucket model; the handler does not call `_resolve_week_window`.
- Single evidence kind `hero_daily_trend`: 12 days x sample_size would be noisy; per-day sample is carried by `value.match_count`.
- Thin relay: preserves STRATZ day desc order, no sorting; bracket translation is a field mapping (basic->full), not an aggregate.
