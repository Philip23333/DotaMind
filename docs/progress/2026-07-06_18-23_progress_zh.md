# MetaMind 进度快照：2026-07-06 18:23

> 本文记录 P1-C1（审计文档 §4-5）：hero_position_stats 扩展 winCount + selection_mode，让 position 工具从「只答出场量」（能力利用率 <5%）升级为「某位置胜率最高/出场最多」「某英雄最强位置」。

## 修改总结

- **集成层**（[heroes.py](apps/api/app/integrations/stratz/heroes.py)）：`_HERO_POSITION_STATS_QUERY` 加 `winCount`；`hero_position_stats` normalize 加 `win_count` + 派生 `match_win_rate = winCount/matchCount`（HeroPositionTimeDetailType.winCount = 整局胜场，故 match 级）。
- **agentic 层**（[stratz_tools.py](apps/api/app/agentic/tools/stratz_tools.py)）：
  - `HeroPositionStatsInput` 加 `selection_mode: strong/popular`（默认 strong）+ `min_sample_size`（默认 300）。
  - `_hero_position_stats_handler`：两分支都用 selection_mode（消除「参数某分支静默无效」）—— `position_id` 分支过滤→排序→take 截断；`hero_id` 分支过滤→排序、**不截断**（返回该英雄完整位置分布按胜率排，能答「最强位置」）。
  - `hero_position_stats_evidence` value 加 `match_win_rate` + `win_count` + `win_rate_basis="match: winCount/matchCount"`（顶层 + filters 双写）；filters 带 selection_mode；新增 `selection_policy` 字符串。
  - description 重写：selection_mode/min_sample_size 对两分支都生效，take 仅 position_id 截断。
- **planner**（[planner.py](apps/api/app/agentic/planning/planner.py)）：`Supported` 段补 position（胜率最高/出场最多/最强位置）；selection_mode 指引补 position（语义同 lane_meta，两分支都生效）。

## 关键设计

- position 胜率口径 = winCount/matchCount（match 级），basis 标 `"match: winCount/matchCount"`，与 lane 的 `"match: matchWinCount/matchCount"` 区分（同口径不同字段）。
- selection_mode 复用 lane_meta 的 strong/popular 语义，但两分支都生效（hero_id 不截断 / position_id 截断 take），避免参数静默无效。
