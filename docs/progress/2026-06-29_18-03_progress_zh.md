# DotaMind 进度快照：2026-06-29 18:03

> 本文记录极薄 ContractCatalog 对齐改动。

## 本次更新

- 扩展 `ContractSpec`，新增：
  - `allowed_evidence`
  - `prompt_example`
- 新增统一契约入口：
  - `known_evidence_kinds(registry)`
  - `render_planner_contracts(registry)`
  - `validate_plan_against_catalog(plan, registry)`
- Planner validation 改为调用 `validate_plan_against_catalog()`，不再在 Planner 内散落校验逻辑。
- Planner prompt 改为从 contract catalog 渲染输出契约、required evidence、allowed evidence 和示例 plan。
- `team_recent_report` 契约补齐真实 evidence 名称：
  - `team_identity`
  - `recent_matches`
  - `current_players`
  - `team_hero_usage`
  - `match_detail_sample`
  - `sample_size`
- 增加 tool args schema validation：
  - 拒绝未知参数，例如 `current_roster`
  - 拒绝错误输入，例如 `opendota.team_heroes.team_id`
  - 允许合法引用，例如 `"$get_matches.data.matches"`
