# DotaMind Progress Snapshot: 2026-06-23 14:17

> This document records the new backend Query Smoke Runner.

## Updates

- Added `apps/api/scripts/query_smoke.py`.
- The runner targets `http://127.0.0.1:8001/api/v1/query` by default.
- Default smoke queries cover:
  - `How Team BB play lately?`
  - `how XG play last 2 months`
  - `how XG play last 1 day`
  - `what changed in patch 7.41d?`
  - `what changed in patch 1.00?`
  - `strongest offlane heroes`
- For each query, it prints:
  - PASS/FAIL
  - HTTP status
  - elapsed ms
  - routed service
  - Critic status/action
  - team-report `matches_in_window`, `match_details_analyzed`, and `latest_match_at`
  - key patch/meta report summary fields
  - source status
- `409 ambiguous_team` and `404 team_not_found` are treated as expected outcomes, so they do not fail the runner by themselves.
- Added usage instructions to `apps/api/README.md`.

## Usage

```text
cd apps/api
python scripts/query_smoke.py
```

Use `--base-url` for another local API instance. Pass `--query` multiple times to override the default query list.
