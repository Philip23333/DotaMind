# MetaMind 进度快照：2026-06-23 11:36

> 本文记录战队报告数据可信度与 freshness 字段的落地。

## 本次更新

- 战队报告新增结构化 `data_freshness` 字段，用于说明报告依据的数据是否足够新。
- `data_freshness` 包含：
  - `latest_match_time` / `latest_match_at`：窗口内最近一场比赛时间。
  - `sample_window_days`：解析后的样本窗口天数。
  - `matches_in_window`：窗口内全部比赛数量。
  - `match_details_analyzed`：实际拉取并分析的比赛详情样本数量。
  - `opendota_cache_hits` / `opendota_cache_misses`：本次战队报告链路内 OpenDota transport 缓存命中与未命中次数。
- `/debug/chat` 的战队报告事实区现在展示最新比赛、样本窗口、详情样本和 OpenDota 缓存命中情况。
- `docs/technical/api.md` 增加 `data_freshness` 字段说明。

## 设计说明

- 保留已有根字段 `matches_in_window` 和 `match_details_analyzed`，避免破坏已有调用方。
- freshness 作为嵌套对象输出，避免继续把底层诊断字段平铺到战队报告根部。
- OpenDota 缓存命中情况来自 transport 的实际 cache stats 前后差值，而不是 UI 或 Formatter 推断。
