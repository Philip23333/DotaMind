# DotaMind Progress Snapshot: 2026-06-22 15:47

> This document records team-report time-range parsing, match-detail sampling, concurrency limits, and caching policy changes.

## Work Completed

### 1. Deterministic Time-Range Conversion

The Retriever now converts the Orchestrator's extracted duration by unit:

```text
last_10_days   -> 10 days
last_3_weeks   -> 21 days
last_2_months  -> 60 days
last_1_year    -> 365 days
```

Unknown values still default to 30 days. `last_2_months` is no longer interpreted as two days.

### 2. Full Window and Detail Sample Separation

Team reports no longer use one `match_limit` to truncate every metric:

```text
All match summaries in the time window
  -> record, win rate, duration, opponents, and sample sufficiency

Most recent match-detail sample
  -> signature heroes and hero-pool depth
```

The default detail sample is 50 matches, with a hard per-report limit of 100. Environment configuration cannot raise the hard limit above 100.

Responses now expose:

```json
{
  "matches_in_window": 42,
  "match_details_analyzed": 42
}
```

`/debug/chat` displays both the window count and detail sample count.

### 3. Match-Detail Concurrency Limit

Match details are fetched in bounded batches through `asyncio.Semaphore`:

```text
default concurrency: 10
hard concurrency limit: 15
```

An individual detail failure is still ignored by aggregation and does not cancel other detail requests.

### 4. Long-Lived Match-Detail Cache

`OpenDotaTransport.get()` now accepts a per-request cache TTL. General OpenDota data keeps the one-hour cache, while immutable historical match details use a 30-day TTL:

```text
/teams, /players, /heroStats -> 1 hour
/matches/{match_id}          -> 30 days
```

The cache still lives in API process memory and is cleared by a service restart. It has not yet moved to Redis or another persistent cache.

### 5. Configuration

```text
DOTAMIND_OPENDOTA_MATCH_DETAIL_SAMPLE_SIZE=50
DOTAMIND_OPENDOTA_MATCH_DETAIL_MAX_SAMPLE_SIZE=100
DOTAMIND_OPENDOTA_MATCH_DETAIL_CONCURRENCY=10
DOTAMIND_OPENDOTA_MATCH_DETAIL_CACHE_TTL_SECONDS=2592000
```
