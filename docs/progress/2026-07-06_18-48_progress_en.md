## Key Design

- Caliber split: synergy uses `pair_win_rate` + `ally_pair: winCount/matchCount`, **not reusing** matchup's `matchup_win_rate` (vs is enemy counter, with is ally synergy — different semantics), preserving the P0 win-rate caliber explicitness.
- evidence kind uses the real registry names `hero_synergy_ranking_row`/`sample_size`, not the v2.5 doc legacy `synergy_win_rate`.
- heroId1 is not a hard dependency (target_hero_id uses the method arg), defending against live direction instability.
