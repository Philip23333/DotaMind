### 新工具

| 工具 | input_model | evidence_kinds | 内部实现 |
|---|---|---|---|
| `stratz.pair_lane_outcome` | `hero_id`, `partner_hero_id`, `is_with` | `pair_lane_winrate`, `sample_size` | `heroes.lane_outcome(hero_id)` → client-side 过滤到 partner |
| `stratz.hero_matchup_ranking` | `hero_id`, `side: Literal["vs"]`, `take=10` (≤50), `min_sample_size=100` | `matchup_ranking_row`, `sample_size` | `heroes.hero_vs_hero_matchup`；**advantage/disadvantage 两组各自排序、各自 top-N，不合并** |
| `stratz.lane_meta_global` | `is_with`, `min_sample_size=200`, `highlight_top=15` | `lane_meta_row`, `sample_size` | `heroes.lane_outcome(None)` 全球查询 → handler 内过滤+排序+截断 top-N，**15,797 行原始数据绝不进 EvidenceGraph** |
| `stratz.hero_position_stats` | `hero_id \| None` XOR `position_id \| None`, `take=15` | `position_stat`, `sample_size` | `heroes.hero_position_stats(groupByPosition=true)`；hero_id 分支返回 ≤5 行，position_id 分支 top `take` |

退役：`stratz.lane_outcome`、`stratz.hero_vs_hero_matchup` 工具，`lane_outcome_evidence`、`hero_matchup_evidence` extractor。

### 集成层 ([heroes.py](apps/api/app/integrations/stratz/heroes.py))

- `lane_outcome(hero_id: int | None, ...)` — `hero_id` 改 Optional，支持全球查询。
- 新增 `hero_position_stats(*, hero_ids=None, position_ids=None, bracket_basic_ids=None, week=None)` 包装 `heroStats.stats(groupByPosition:true, ...)`，返回 `[{hero_id, position, match_count}]`。
- `hero_vs_hero_matchup` 不变。

### 关键设计决策

- **advantage/disadvantage 不合并**：两组的 `synergy` 方向相反，合并会产出错误排序。各自 top-N，evidence `value.source_side` 标注来源组。
- **lane_meta_global 在 handler 截断**：手测确认全球 laneOutcome 在 LEGEND_ANCIENT 返回 15,797 行。handler 必须按 `min_sample_size` 过滤、按 `match_count` 排序、截 `highlight_top`，**只让 top-N 行进 ToolResult.data 与 EvidenceGraph**。返回 `total_available` / `returned_count` / `selection_policy` 三个字段（per-tool 约定，**不是 ToolResult contract 字段**，避开 `data_truncation` 这个看起来像契约的名字）。
- **`hero_position_stats` XOR**：用 Pydantic `@model_validator(mode="after")` 在 input_model 层强制 `hero_id XOR position_id`，不在 `contracts.py` 里写 `if tool == ...` 业务特判。
- **`side="vs"` 暂只支持此值**：底层 `_HERO_VS_HERO_MATCHUP_QUERY` 只 select `vs { ... }` 子字段；扩 `with { ... }` 留给后续，prompt 已注明限制。
- **lane_meta_global 按 match_count 排序**：tool description 明说 "returns high-sample lane pair rows, not necessarily strongest by win rate"。常见组合 ≠ 最强组合。
