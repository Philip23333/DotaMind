## PlanRunner 规则

- 输入：`ExecutionPlan`。
- 输出：`PlanRunResult`，包含：
  - `plan`
  - `tool_results`
  - `status`
  - `errors`
- 顺序执行 `tool_calls`。
- 支持最小变量引用：
  - `"$resolve_target.data.hero.hero_id"`
- 如果超过 `constraints.max_tool_calls`，plan 直接失败。
- 如果 tool call id 重复，plan 直接失败。
- 如果引用目标不存在、前置工具失败或引用路径不存在，依赖该引用的工具不会执行，并返回明确 error。
