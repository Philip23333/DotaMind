# DotaMind Progress Snapshot: 2026-06-29 16:21

> This snapshot records the Contract Registry consolidation for `/api/v1/plan`.

## Updates

- Added `app/agentic/contracts.py` as the central registry for agentic output contracts.
- Contract Registry now owns:
  - valid `output_contract` values
  - structured / natural language route
  - required evidence per contract
  - required tools per contract
  - allowed `required_evidence` per contract
  - required intent per contract
- Registered contracts:
  - `patch_impact_report`
  - `role_meta_report`
  - `team_recent_report`
  - `hero_matchup_report`
  - `draft_advice`
  - `natural_language_answer`
- `meta_list` remains the structured contract whitelist, not a valid `output_contract`.
- `AgenticPlanner` no longer owns local contract/evidence constants and now calls `validate_contract_plan()`.
- `AnswerSynthesizer` no longer imports the structured contract list from planner and routes through Contract Registry.
- `response_node` no longer hardcodes structured report contract names; successful answers use the registered contract as `response_type`.
- Added `test_agentic_contracts.py` for registry and contract validation coverage.
