## Key Design

- **evidence-first**: filter preserves the full original ranking row (source_side/synergy/matchup_win_rate/pair_win_rate/sample) + attaches the position sample, so the answer can say "this POSITION_4 hero counters Lina, synergy X, sample Y" — not just an ID list.
- **thin relay**: filter does a set intersection (rule) + pass-through, no invented role composite; `role_fit_basis = "position_sample: matchCount@POSITION_N"`.
- **list[dict] ref**: candidate_rows is a whole-list ref (`$matchup.data.candidate_rows`); `_resolve_reference` returns list[dict] (confirmed supported); contracts `list[dict]` type validation (confirmed).
