# DotaMind Progress Snapshot: 2026-06-29 17:35

> This snapshot records Planner raw content observability when JSON parsing fails.

## Updates

- Added `LLMJSONDecodeError` so `complete_json()` can expose unparsed LLM `content` on JSON decode failure.
- `complete_json()` now raises `LLMJSONDecodeError` when `json.loads(content)` fails, preserving:
  - `raw_content`
  - `finish_reason`
  - the original JSON parse error
- Logs only record raw content length and error details, not the full partial content.
- Added these fields to `AgenticPlannerResult`:
  - `raw_content`
  - `finish_reason`
- Planner still returns `status="error"` when it catches `LLMJSONDecodeError`; it does not fallback, but it now carries the partial planner content.
- Added these fields to the `/api/v1/plan` response:
  - `planner_raw_content`
  - `planner_finish_reason`
- Added a `Planner Raw Content` section to `/debug/plan` so truncated planner JSON can be inspected directly.

## Boundaries

- Did not add fallback behavior.
- Did not add mock data.
- Did not change `/api/v1/query`.
- Only exposes `choice.message.content`, not the full HTTP response.
