  - LLM failures still return `answer.status="error"` with no fallback and no mock data.

  - Always emits `hero_stats`.
  - Always emits `role_fit`.
  - Adds `sample_size` evidence from the role-filtered hero row count.

  - `role_meta_report` must require `hero_stats`.

  - `answer.status="insufficient_evidence"` -> `insufficient_evidence`
  - `answer.status="error"` -> `answer_error`
  - Successful structured reports return their contract, such as `role_meta_report`.
  - Successful natural-language answers return `natural_language_answer`.
