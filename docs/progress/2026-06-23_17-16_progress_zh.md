# MetaMind 进度快照：2026-06-23 17:16

> 本文记录 v2.5 `resolve_hero` 工具的新增。

## 本次更新

- 新增本地英雄常量文件：
  - `apps/api/app/data/heroes/dota2_heroes.yaml`
  - 包含 127 个 Dota 2 英雄的 `id`、`name`、`localized_name`、`aliases`。
  - 运行时只读取本地文件，不依赖 OpenDota 或 STRATZ 实时请求。
- 新增本地英雄解析器：
  - `apps/api/app/agentic/hero_resolver.py`
- 新增 Tool Registry 工具：
  - `resolve_hero`
  - 输入：`query`
  - 输出：`resolved` / `ambiguous` / `not_found` 三态解析结果。
- 更新 `agent_tool_debug.py`：
  - 支持 `--query` 参数。

## 解析策略

- 先做规范化：
  - trim
  - lowercase
  - 移除 apostrophe
  - `-` / `_` 转空格
  - 合并多空格
- 匹配顺序：
  - 精确匹配 `localized_name`
  - 精确匹配内部 hero slug
  - 精确匹配 aliases
  - 模糊匹配候选
- 结果三态：
  - `resolved`：唯一命中。
  - `ambiguous`：多个合理候选，例如 `es` 同时命中 Earthshaker / Earth Spirit。
  - `not_found`：没有候选。
