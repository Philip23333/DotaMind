## 本轮目标

恢复换环境后丢失的两个运行时数据源，并消除“文件只在旧工作区存在”的风险：

- `apps/api/app/data/heroes/dota2_heroes.yaml`
- `apps/api/app/data/patches/7_41d.json`

## 根因

- 两个文件从未进入 Git 历史，无法从提交对象恢复。
- 根 `.gitignore` 的 `data/` 会匹配任意层级的 `data` 目录，导致
  `apps/api/app/data/` 被整体忽略。
- 运行时代码硬读本地快照，但仓库没有同步脚本，换机器后无法重建。

## 实现

- 将忽略规则改为仅忽略仓库根目录 `/data/`，使 API 的规范数据可提交。
- 新增 `scripts/sync_game_data.py`：离线读取 Valve 官方 Dota 2 datafeed，生成
  英雄常量和指定/最新补丁；运行时请求链路不联网、不回退生成。
- 新增 `scripts/hero_aliases_zh.yaml`：在 Valve 官方简体中文英雄名上叠加可审查的
  社区俗称；`ES` 同时保留给 Earthshaker/Earth Spirit，继续返回 ambiguous。
- 生成英雄快照：127 个英雄，包含 ID、内部名、英文展示名、官方中文名和俗称。
- 生成 7.41d 补丁快照：发布时间 `2026-06-04T07:00:00Z`，203 条变更；来源 URL
  写入 JSON。polarity 使用保守规则，无法可靠判断时标为 `neutral`。
- 修正 patch reader：显式请求不存在的版本不再静默回退 latest；latest 使用版本号
  排序而不是文件名字典序。
- `docs/technical/configuration.md` 增加数据来源、同步命令和人工审查边界。
