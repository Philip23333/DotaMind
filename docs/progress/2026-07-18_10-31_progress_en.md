## Compatibility boundary

- The project is still in active development and does not retain compatibility
  aliases for previous brand identifiers, environment variables, package names,
  or documentation paths.
- Deployments and local development environments must use `DOTAMIND_*`.
- Existing Docker PostgreSQL volumes initialized with different legacy database
  or user names must be reinitialized or migrated manually to the new
  `dotamind` defaults.
