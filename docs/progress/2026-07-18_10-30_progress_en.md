# DotaMind Progress Snapshot: 2026-07-18 10:30

## Session-memory follow-up corrections

- `player_profile_evidence()` now consumes only the handler's
  `confirmed_steam_account_id`. The player-tool suite covers the complete
  handler → `ToolResult` → evidence path.
- Stateful safe failures persist a dedicated redacted `Turn`: it records only
  the current query, coarse status, stable summary, and
  `response_type="session_request_failed"`. Rejected plans, model reasons,
  validation input, context, and prior-history sentinels cannot become future
  session memory.
- `SessionStore.append()` now requires the current task to hold
  `transaction(session_id)`. This makes get → run → append an explicit atomic
  contract and prevents an unlocked direct append from creating and immediately
  evicting a new session while another active session fills capacity.
- The planner prompt makes `stratz.player_profile` mandatory before
  `stratz.player_recent_matches` and `stratz.player_hero_performance`, with the
  confirmed Steam32 output required as the downstream reference.
