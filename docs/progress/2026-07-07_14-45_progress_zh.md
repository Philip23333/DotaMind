## Sample Policy 阶段 1

本轮把 `min_sample_size` / `min_position_match_count` 从零散默认值收敛为 planner 参数策略层：

- 新增 `planning.sample_policy` 配置段（[policy.yaml](../../apps/api/app/config/policy.yaml)）：按工具声明 `arg/default/relaxed/strict`。
- 新增配置模型（[config.py](../../apps/api/app/core/config.py)）：`PlanningPolicy`、`SamplePolicyConfig`、`SamplePolicyToolEntry`，并校验 `relaxed <= default <= strict`。
- 新增 Sample Policy 渲染与兜底模块（[sample_policy.py](../../apps/api/app/agentic/planning/sample_policy.py)）：
  - `render_sample_policy(policy, registry)` 把四类模式和 per-tool 阈值表注入 planner prompt。
  - 渲染时校验 policy tool 名必须存在于 registry，`arg` 必须是对应 input model 字段，防止配置 typo 静默失效。
  - `apply_sample_policy(plan, policy)` 在 LLM 漏填或填 `null` 时补 policy `default`，并把注入记录写入 `plan.metadata["policy_applied"]`。
- planner 接入点在 [planner.py](../../apps/api/app/agentic/planning/planner.py)：`AgenticPlanner.plan()` 内部、envelope 解析后、catalog validation 前调用 `apply_sample_policy`，因此 `AgenticPlannerResult.plan` 即最终 plan。
- `ExecutionPlan` 新增 `metadata` 字段，用于记录 planner 层策略注入 provenance。
- STRATZ 5 个工具默认值与 policy default 对齐：
  - `stratz.hero_matchup_ranking.min_sample_size`：2000
  - `stratz.hero_synergy_ranking.min_sample_size`：2000
  - `stratz.lane_meta_global.min_sample_size`：1000
  - `stratz.hero_position_stats.min_sample_size`：1000
  - `stratz.filter_heroes_by_position.min_position_match_count`：1000

## 行为语义

- 普通 counter/synergy 推荐默认使用大样本阈值（matchup/synergy 为 2000）。
- 用户明确说“至少 N 场”时，LLM 应直接填 N，post-process 不覆盖。
- 用户表达“稳健 / 高置信 / 大样本”时，planner prompt 指引使用 strict。
- 用户表达“冷门也行 / 小样本也可以 / 边缘英雄”时，planner prompt 指引使用 relaxed。
- 阶段 1 只做 planner 参数策略和默认兜底；不做 critic 稀疏样本检查，也不做 critic -> planner retry 回环。
