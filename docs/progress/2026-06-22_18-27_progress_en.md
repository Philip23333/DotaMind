# MetaMind Progress Snapshot: 2026-06-22 18:27

> This document records local backend startup port pinning and related documentation synchronization.

## Updates

- Added root-level `dev-api.cmd` for starting the FastAPI backend on Windows during local development.
- `dev-api.cmd` pins the API to `127.0.0.1:8001` and checks whether port `8001` already has a listening connection before startup.
- If `8001` is occupied, the script prints an error and exits non-zero instead of trying another port.
- Updated root `package.json` so `npm run dev:api` calls `dev-api.cmd`.
- Updated `README.md`, `apps/api/README.md`, and `docs/technical/api.md` from local backend port `8000` to `8001`.
