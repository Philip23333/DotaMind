# MetaMind Progress Snapshot: 2026-06-25 16:19

> This snapshot records the aggressive refactor of `/api/v1/plan` from a linear service / PlanRunner mix into a LangGraph-compatible Tool / Node structure.

## Updates

- Added `apps/api/app/agentic/nodes.py`:
  - `planner_node`
  - `validate_plan_node`
  - `tool_executor_node`
  - `evidence_node`
  - `answer_node`
  - `critic_node`
  - `formatter_node`
- Added `apps/api/app/agentic/graph.py`:
  - `AgentGraphRunner`
  - Handles minimal conditional routing without adding LangGraph runtime.
- Removed `PlanRunner / PlanRunResult`:
  - Deleted `apps/api/app/agentic/runner.py`
  - Reference resolution moved into `tool_executor_node`.
  - Plan validation moved into `validate_plan_node`.
  - Evidence graph construction moved into `evidence_node`.
- Removed `PlanFormatter`:
  - Deleted `apps/api/app/agentic/formatter.py`
  - `formatter_node` now writes `AgentRunState.response` directly.
- Simplified `ToolExecutor`:
  - Removed `execute_plan()`.
  - Kept single-tool execution via `execute(call)`.
- Updated `PlanService`:
  - Creates `AgentRunState`.
  - Calls `AgentGraphRunner`.
  - No longer directly orchestrates planner/runner/answer/critic.
- Fixed Planner contract:
  - Counter-pick plans must use `output_contract="draft_advice"`.
  - Validation rejects `counter_pick + tool_results`.

## Current Path

```text
AgentGraphRunner
  -> planner_node
  -> validate_plan_node
  -> tool_executor_node
  -> evidence_node
  -> answer_node
  -> critic_node
  -> formatter_node
```

## Behavior Boundary

- LangGraph runtime was not introduced.
- No new business tools were added.
- No ResponseAgent was added.
- `/api/v1/query`, `/debug/chat`, and the legacy report pipeline are unchanged.
- Tool execution errors still flow into `evidence_node`, producing an inspectable EvidenceGraph.
- Planner insufficient/error responses do not execute tools and go directly to formatter.
