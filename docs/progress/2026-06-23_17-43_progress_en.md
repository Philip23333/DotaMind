## PlanRunner Rules

- Input: `ExecutionPlan`.
- Output: `PlanRunResult`, including:
  - `plan`
  - `tool_results`
  - `status`
  - `errors`
- Executes `tool_calls` sequentially.
- Supports minimal variable references:
  - `"$resolve_target.data.hero.hero_id"`
- If the plan exceeds `constraints.max_tool_calls`, the plan fails immediately.
- If tool call IDs are duplicated, the plan fails immediately.
- If a reference target is missing, a dependency tool failed, or a reference path is missing, the dependent tool is not executed and a clear error is returned.
