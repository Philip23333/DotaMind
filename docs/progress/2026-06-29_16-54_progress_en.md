# DotaMind Progress Snapshot: 2026-06-29 16:54

> This snapshot records the Tool Evidence Extractor registry refactor for `/api/v1/plan`.

## Updates

- Added optional fields to `ToolDefinition`:
  - `evidence_extractor`
  - `evidence_kinds`
- `EvidenceGraph` no longer hardcodes extractor branches by tool name.
- `build_evidence_graph(plan, tool_results, registry)` now reads tool definitions from `ToolRegistry`:
  - tools with `evidence_extractor` produce `EvidenceItem`
  - tools without extractors keep their `ToolResult` but produce no evidence
  - unknown tools or extractor failures are surfaced in `missing`
- Migrated existing extractors into their tool modules:
  - `stratz_tools.py`: `resolve_hero`, `stratz.hero_vs_hero_matchup`, `stratz.lane_outcome`
  - `opendota_tools.py`: team, player, and hero stats tools
  - `patch_tools.py`: patch records, hero changes, and item changes
- Planner known evidence kinds are now derived from `definition.evidence_kinds` in the registry.
- `evidence_node` now receives the registry explicitly and passes it into EvidenceGraph.

## Boundaries

- Did not add new business tools.
- Did not change `/api/v1/query`.
- Did not change the response schema.
- Did not add fallback behavior.
- Did not add mock data.
- `ToolExecutor` still only executes tools and does not produce evidence directly.
