# DotaMind 进度快照：2026-06-23 14:17

> 本文记录后端 Query Smoke Runner 的新增。

## 本次更新

- 新增 `apps/api/scripts/query_smoke.py`。
- Runner 默认请求 `http://127.0.0.1:8001/api/v1/query`。
- 默认 smoke queries 覆盖：
  - `How Team BB play lately?`
  - `how XG play last 2 months`
  - `how XG play last 1 day`
  - `what changed in patch 7.41d?`
  - `what changed in patch 1.00?`
  - `strongest offlane heroes`
- 输出每条 query 的：
  - PASS/FAIL
  - HTTP status
  - elapsed ms
  - routed service
  - Critic status/action
  - team report 的 `matches_in_window`、`match_details_analyzed`、`latest_match_at`
  - patch/meta report 的关键摘要字段
  - source status
- `409 ambiguous_team` 和 `404 team_not_found` 被视为可预期结果，不会让 runner 直接失败。
- `apps/api/README.md` 增加 runner 使用说明。

## 使用方式

```text
cd apps/api
python scripts/query_smoke.py
```

可通过 `--base-url` 指向其他本地 API 实例，也可以多次传入 `--query` 覆盖默认 query 列表。
