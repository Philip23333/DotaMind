## Layer Boundary (two residual issues from review — neither is in the planner prompt layer)

1. **"strongest" framing drift (answer layer)**: `lane_meta_global` selects top-N by `match_count` (its description explicitly warns "common not strongest"), yet the answer labeled these "the strongest ally lane pairs" — really "highest-winrate among the most-played". This is the answer node not honoring a caveat that **already lives in the prompt's tool description**; not a prompt problem.
2. **Time-window gap (upstream tooling layer)**: `context.week` is a single epoch while "last two weeks" is a range (mismatched semantics), and the planner **has no way to fetch the current week epoch**, so the prompt rule "for last N weeks use the most recent week epoch" is effectively empty guidance — the model can only set None. Root cause is a missing tool/data source, not prompt wording.

## Follow-up Backlog (out of scope for this refactor)
