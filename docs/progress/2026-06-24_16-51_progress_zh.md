# MetaMind 进度快照：2026-06-24 16:51

> 本文记录 v2.5 `/api/v1/plan` 骨架闭环补齐：从原来的 raw evidence response，推进到 AnswerSynthesizer、AgenticCritic、PlanFormatter 的完整后半段结构。

## 本次更新

- 新增 `AgentRunState`：
  - `apps/api/app/agentic/state.py`
  - 作为 `/api/v1/plan` 的内部状态对象。
  - 统一承载 query、plan、tool results、evidence graph、answer、review、errors、trace。
- 新增 `AnswerSynthesizer`：
  - `apps/api/app/agentic/answer.py`
  - 输入 `ExecutionPlan + EvidenceGraph`。
  - 输出结构化 `AnswerSynthesisResult`。
  - 第一版支持 `output_contract="draft_advice"` 且 `intent="counter_pick"`。
  - 缺少 required evidence 时返回 `answer.status="insufficient_evidence"`。
  - 不调用 LLM、不查新数据、不 fallback、不 mock。
- 新增 `AgenticCritic`：
  - `apps/api/app/agentic/critic.py`
  - 输入 `ExecutionPlan + EvidenceGraph + AnswerSynthesisResult`。
  - 检查 missing evidence、mock source、tool failure、answer status、answer confidence。
- 新增 `PlanFormatter`：
  - `apps/api/app/agentic/formatter.py`
  - 将 `AgentRunState` 转为 `/api/v1/plan` API envelope。
- 更新 `/api/v1/plan` 响应：
  - 新增 `answer`
  - 新增 `review`
  - 新增 `trace`
- 更新 debug CLI：
  - `apps/api/scripts/agent_plan_llm_debug.py`
  - 输出同步包含 `answer/review/trace`。

## 当前链路

AgenticPlanner

  -> PlanFormatter
  -> PlanResponse
